# Lab 06 — Filters: Comparison & Logical Operators

## Database Systems

This folder contains the SQL work for **Lab 06 — Part A: Comparison & Logical Operators**.

### SQL File

- `Lab06_Filters.sql`

### Table Used

The queries assume an `Employee` table with these columns:

```text
EmpID
EmpName
Gender
Salary
City
Department
JobTitle
HireDate
```

### Topics Covered

This lab demonstrates filtering records using:

- Greater than (`>`)
- Less than or equal to (`<=`)
- Equality (`=`)
- Not equal to (`<>`)
- `AND`
- `OR`
- Multiple conditions

### Tasks Covered

The SQL file includes queries for:

- Employees earning more than 90,000
- Employees earning 75,000 or less
- Employees from Lahore with salary above 90,000
- Employees from Karachi or Islamabad
- Female employees outside the Engineering department
- Male employees with salaries from 70,000 to 90,000
- Software Engineers or employees earning above 100,000
- Employees who are not in Marketing or Sales

### How to Run

1. Open `Lab06_Filters.sql` in MySQL Workbench.
2. Make sure the `Employee` table exists.
3. Run the queries individually or execute the script.
