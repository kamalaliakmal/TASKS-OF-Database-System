# Lab 10 — Scalar Functions (String Functions)

## Database Systems

This folder contains the MySQL SQL file for **Lab 10: Scalar Functions — Part 01 (String Functions)**.

### File Included

- `RollNo_ScalarFunctions_Lab10.sql`

### Topics Covered

The SQL file demonstrates MySQL string/scalar functions including:

- `TRIM()`
- `UPPER()`
- `LOWER()`
- `CHAR_LENGTH()`
- `CONCAT()`
- `SUBSTRING_INDEX()`
- `LEFT()`
- `REPLACE()`
- `LPAD()`
- `LOCATE()`
- `SUBSTRING()`

### Tasks Covered

The file contains solutions for:

- **A1:** Remove leading and trailing spaces from customer names.
- **A2:** Display customer names in uppercase and lowercase.
- **A3:** Display trimmed names with character counts.
- **A4:** Create a customer greeting.
- **A5:** Extract email usernames.
- **A6:** Extract email domains.
- **A7:** Display the first three characters of customer names.
- **A8:** Mask customer phone numbers.
- **A9:** Replace spaces in product names with hyphens.
- **A10:** Pad product IDs with leading zeros.
- **A11:** Find product names containing `Pro` and its position.
- **A12:** Extract each customer's first name.

### How to Run

1. Open MySQL Workbench or another MySQL client.
2. Make sure the database containing the `Customer` and `Product` tables is selected.
3. Open `RollNo_ScalarFunctions_Lab10.sql`.
4. Execute the queries individually or as a script.

> **Note:** The SQL file assumes that the required database schema and tables already exist.
