# Lab 09 — Joins Part 02

## Database Systems

This folder contains the SQL work for **Lab 09 — Joins Part 02: Self Joins, Multi-table Joins, and Combined Challenges**.

### SQL File

- `Lab09_Joins.sql`

### Company Schema

The queries assume these tables:

- `Employee`
- `Department`
- `Project`
- `Assignment`

### Topics Covered

This lab demonstrates:

- Self joins
- Manager-employee relationships
- Multi-table joins
- `INNER JOIN`
- `LEFT JOIN`
- `COALESCE()`
- `SUM()`
- Subqueries
- `DISTINCT`
- Filtering across related tables

### Tasks Covered

The SQL file includes queries for:

- Employees and their managers
- Employees earning more than their managers
- Employees and managers from different departments
- Employee project assignments
- Assignment details with project departments
- Employees assigned to the Mobile App project
- Employees from departments located in Lahore
- Employees working on projects outside their department
- Departments and projects started during 2024
- Total weekly assignment hours for each employee

### How to Run

1. Open `Lab09_Joins.sql` in MySQL Workbench.
2. Make sure the company schema tables exist.
3. Run the queries individually or execute the complete script.
