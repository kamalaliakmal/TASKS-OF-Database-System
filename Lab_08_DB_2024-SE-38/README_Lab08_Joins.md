# Lab 08 — Joins Part 01

## Database Systems

This folder contains the SQL work for **Lab 08 — Joins Part 01: INNER, LEFT, RIGHT Joins**.

### SQL File

- `Lab08_Joins.sql`

### Company Schema

The queries assume these tables:

- `Employee`
- `Department`
- `Project`
- `Assignment`

### Topics Covered

This lab demonstrates:

- `INNER JOIN`
- `LEFT JOIN`
- Combining employee and department information
- Finding employees without assignments
- Finding projects without assignments
- Filtering joined records
- `GROUP BY` with joins
- `UNION`

### Tasks Covered

The SQL file includes queries for:

- Employees with their departments and locations
- All employees including those without matching departments
- All departments including departments without employees
- Projects with their departments
- Employees without project assignments
- Projects without assignments
- Engineering employees sorted by salary
- Employees working in Lahore departments
- Employee counts per department
- Combining employee and department records using `UNION`

### How to Run

1. Open `Lab08_Joins.sql` in MySQL Workbench.
2. Make sure the company schema tables exist.
3. Run the queries individually or execute the complete script.
