# Lab 11 — Scalar Functions (Numeric & Date/Time Functions)

## Database Systems

This folder contains the MySQL SQL file for **Lab 11: Scalar Functions — Part 02 (Numeric & Date/Time Functions)**.

### File Included

- `RollNo_ScalarFunctions_Lab11.sql`

### Topics Covered

The SQL file demonstrates MySQL numeric and date/time functions including:

- `ROUND()`
- `FLOOR()`
- `CEIL()`
- `MOD()`
- `YEAR()`
- `MONTHNAME()`
- `DAYNAME()`
- `DATE_FORMAT()`
- `TIMESTAMPDIFF()`
- `DATEDIFF()`
- `DATE_SUB()`
- `DATE_ADD()`
- `CURDATE()`
- `CONCAT()`

### Tasks Covered

The file contains solutions for:

- **B1:** Apply a 15% discount to products.
- **B2:** Calculate 17% sales tax and final price.
- **B3:** Calculate floor and ceiling of price divided by 1000.
- **B4:** Round product prices to the nearest hundred.
- **B5:** Find products with odd product IDs.
- **B6:** Display the year, month name, and day of the week for customer join dates.
- **B7:** Format dates of birth as `DD-Month-YYYY`.
- **B8:** Calculate current customer age in years.
- **B9:** Calculate the number of days since each customer joined.
- **B10:** Find customers who joined in 2023.
- **B11:** Find products launched in Q4.
- **B12:** Find customers who joined within the last six months.
- **B13:** Calculate product age in days.
- **B14:** Calculate the date 90 days after product launch.
- **B15:** Create a combined customer summary.

### How to Run

1. Open MySQL Workbench or another MySQL client.
2. Select the database containing the `Customer` and `Product` tables.
3. Open `RollNo_ScalarFunctions_Lab11.sql`.
4. Execute the queries individually or as a script.

> **Note:** The SQL file assumes that the required database schema and tables already exist.
